# Ch7 브라우저 QA와 발견 사항

기준 통합 `28d80fc` 이후, localhost:3011·별도 QA SQLite·격리 Chrome/CDP9337. 운영 데이터/배포는 사용하지 않았다. 앞 씬·레슨·드릴 3스텝만 운영자 skip으로 생략하고 **라이브 관찰12핸드와 퀴즈4문항은 실제 화면 버튼/실제 덱**으로 진행했다. 앞 7드릴을 직접 푼 검증은 구현자의 실제소켓 테스트에 별도로 있다.

## 확인한 것

- 관찰 중 이름·아바타가 가면 A~D이며 봇 한 명이 4번째 핸드에 파산한 뒤에도 나머지 12핸드 관찰→4문항이 이어졌다. 파산한 가면 A의 노트는 4핸드로 유지하고 다른 가면은 12핸드를 표시했다.
- 390×844 첫 질문은 366×450 패널로 선택지4개와 전체 질문이 보였다.
- 2번 질문에서 320×700으로 축소 후 390×844 새로고침. 같은 2/4 질문과 확정된 첫답이 유지되고 제한시간은 23→22초로 이어져 리셋되지 않았다.
- 관찰 기록만 보고 A 니트/B ABC/C 블러퍼/D 스테이션을 선택했다. 1~3답 뒤 정답/캐릭터가 보이지 않았고 네답이 확정되자 모찌/초코/구미/클로이와 4정답 피드백이 함께 공개됐다.
- 공개 후10핸드를 실제 체크/폴드로 마치고 에필로그→결산까지 완료했다. 행동 대응 기회는0회라 해당 없음, 필수퀴즈4/4는 달성, 파산 없음이었다. 결산 직후 지갑11,600→12,400, 도장Lv7→8, 비비안 인연100XP를 표시했다. Ch7 하나로 갈색띠를 주지 않았다. 앞 드릴은 운영자skip으로 통과시켰으므로 화면의7/7·PERFECT 표시는 직접 문제풀이 검증으로 집계하지 않는다.

## 통합 전에 수정할 UI 문제

**P2: 퀴즈/정답 패널이 테이블의 clipped stacking context에 갇힌다.** `StoryOverlay`의 absolute 래퍼와 `MasqueradePanel`의 role=dialog section은 공용 Modal을 거치지 않는다. 320×700 질문 상단이 TopBar/배너 뒤에 가려지고, 390×844 긴 정답 패널은 y=96.109/h=590.797인데 상단115px·하단667px 크롬에 잘린다. 스크롤하면 계속 버튼을 누를 수 있지만 제목이 계속 가려진다. 사진: `qa-tmp/expansion-live/r2-quiz-320.png`, `r2-quiz-feedback-mobile.png`.

**P2: ARIA modal 선언과 달리 키보드 포커스가 밖으로 나간다.** 피드백에서 Tab8회: 계속 버튼(inside true)→body→개발도구→뒤로←→사운드→핸드히스토리→도움말→설정(모두 false). `quiz-a11y.cjs`로 재현했다.

수정 계약: 공용 `Modal`에 기본 true인 `dismissible` 옵션을 추가하고 이 퀴즈만 false로 쓴다. false이면 닫기 버튼·배경 클릭·Escape 닫기를 비활성화하되 기존 다른 모달 계약을 유지한다. 최초 초점은 첫 유효 버튼 또는 dialog이며 Tab/Shift+Tab을 가둔다. pending/offline으로 모든 버튼이 비활성이면 dialog에 초점을 둔다. 퀴즈 질문/피드백 변경 때 초점과 내부 스크롤을 새 내용 시작으로 복구한다. 질문 선택/정답은 서버 절대 deadline을 그대로 사용한다. 제한시간은 0~30초로 clamp해 250ms 렌더 간격 때문에 순간31초가 보이는 현상도 없앤다. 관찰 노트의 비모달 details는 기존 테이블 하단에 둔다.

수정 뒤 320/390/1280 화면·네 선택지/정답 마지막 계속 버튼 접근·Tab/Shift+Tab·Escape/배경 클릭·기존 닫을 수 있는 미션 상세 모달을 확인한다. 실기기 터치와 스크린리더 음성은 아직 검증하지 않았다.
# 모바일 모달 수정 재검증

- `86ac82a`의 실제 `MasqueradePanel`/공용 `Modal`을 임시 개발 라우트에서 렌더하고, 500px 높이의 `overflow:hidden`·transform 부모 안에 넣어 기존 잘림 조건을 재현했다. 서버 게임 흐름 검증은 위 실제 플레이 기록과 구분하며, 여기서는 긴 설명을 가진 합성 DTO로 화면 경계를 검사했다. 임시 라우트는 확인 후 삭제했다.
- 320×700 / 390×844 / 1280×900의 질문·4개 긴 해설 모두 가로 넘침 없이 표시됐고, 내부 스크롤로 마지막 계속 버튼 전체에 접근했다. 320 해설은 패널 288×668, 본문 높이 574 / 전체 1192px였다.
- Tab·Shift+Tab 순환, Escape·배경 클릭으로 필수 퀴즈가 닫히지 않음, 질문 교체 시 스크롤·첫 버튼 포커스 초기화를 확인했다. 오프라인으로 모든 선택지가 비활성화되면 대화상자 자체가 포커스를 유지하고, 뒤쪽 버튼에 프로그램으로 포커스를 보내도 복구됐다.
- 기존 닫을 수 있는 미션 모달의 Escape·닫기 버튼 동작도 유지됐다. 화면 캡처 320px 긴 해설 및 390px 질문을 직접 확인했다. 로컬 증거: `qa-tmp/expansion-live/r2-modal-fixture-results.json`, `r2-modal-{quiz,feedback}-{320,390,1280}.png`.
