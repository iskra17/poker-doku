# 승인된 수련 확장 실행 기록

사용자는 2026-09-05 로드맵의 1~4번을 승인하고 구현 시작을 지시했다. Astra 총괄, Fable 5.1 기획/심층 검증, Astra Medium/Claude Opus 구현 분담을 적용한다.

- [ ] R1c 실제 소켓/브라우저로 기존 수련 완결성 확인
- [ ] A1 일반 수련·일상 이미지 24후보 파일럿
- [ ] A2 영속 제작 큐·중단 복구·일시정지·검수·export
- [ ] A2 승인 장면을 게임 CG/영상에 연결
- [ ] R2 Ch7 퀴즈·가면 공개·허브/보상·완주

성적 흥분 목적의 노골적 보너스 CG 및 제한 우회용 로컬 LLM 위임은 수행하지 않는다. 일반 수련/일상 아트 제작과 1~4번 구현은 독립적으로 계속한다. MTT 공개 숨김 유지, 하드 모드/질문권/멀티테이블은 이번 구현 범위 밖이다. push/deploy는 별도 지시 전까지 실행하지 않는다.

## 현재 배치

기준 main `92e508b`(이미 미푸시 커밋 2개). `story-expansion-control`은 총괄 계획/통합용, `story-progression-rewards`는 R1a 설계/구현, `art-library-pilot`은 A1 전용 worktree다. 동시 작업자는 2명 이하이며 GPU는 A1 담당만 소유한다.

- R1a: Astra Medium 구현 `7c04834`, 관련 12파일 387테스트/tsc 통과. Fable 사후 검토와 통합 대기.
- R1b: Astra Medium 구현 `24f26de`, 관련 92테스트(실소켓11 포함)/tsc 통과. Fable 사후 검토와 브라우저 검증 대기.
- A1: 최초24+보정12=36장 생성·검수, 358.29초. 기존 SDXL 레시피는 정체성/구도 품질 gate 미달로 export 0장. 실험 기록 `f2ebd0f`를 총괄 브랜치에 `82a1df4`로 통합했다.
- A1c: 원본 캐릭터를 참조하는 일반 수련/일상 장면의 Qwen-Image-Edit 2511 로컬 비교 실험 준비. 공식 Comfy-Org 모델+인코더+VAE와 공식 문서의 Lightning 레시피를 내려받고 해시 검증한다. GPU 추가 생성은 아직 시작하지 않았다.
- A2: 영속 큐 계약 `2026-09-05-art-queue-design.md` 작성, 검토 전.
- R2: Ch7 가면 퀴즈·상대 대응·커리큘럼 계약 `2026-09-05-ch7-live-quiz-design.md` 작성, 검토 전.
- 총괄 QA: 임시 별도 DB와 localhost:3011 서버, 격리 Chrome/CDP 9337에서 390px 실제 라이브 미션 상세와 턴 만료를 확인했다. 모달 닫기→계속하기로 새 핸드 예약, 1280px 상세도 확인 중. 운영/실기기 검증은 아니다.
