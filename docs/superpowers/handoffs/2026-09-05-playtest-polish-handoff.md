## 반영한 수정

1. 수기 캐릭터 대사·스토리·드릴·봇 해설에서 핸드/폴드/벳 표현을 교정했다. `poker-terminology.ts`가 AI 프롬프트 규칙과 대표적인 오역 거부 판정의 공용 모듈이다. 새 생성 대사와 기존 디스크 캐시에서 해당 오역을 거르고 안전한 기존 대사로 폴백한다. 신체의 손과 꽃다발 등 실제 아이템 투척은 허용한다. 모든 자연어 오역을 판별하는 문법 검사기는 아니므로 추가 사례는 회귀 문장으로 축적한다.
2. `ObjectiveHud`의 미션 행과 [미션 전체보기]에서 전체 문구·통과 조건/보너스·판정 상태·진행 수치를 읽는 모달을 연다. 상세 수치는 0회 상한과 초과 횟수를 보존한다. 미션을 읽는 동안에도 턴 타이머는 흐른다. 스텝 변경 시 모달 상태를 초기화한다.
3. 공개 MTT 진입점을 기본적으로 숨겼다. `NEXT_PUBLIC_MTT_ENABLED=true`로 빌드해야 다시 나타난다. 토너먼트 탭·카드·복귀 배너·개설·초대 링크/코드 진입을 함께 처리했다. 서버와 `/admin` 운영 기능은 유지한다. 범위 질문에 추가 응답이 없어 **MTT만 숨기고 Sit & Go는 유지**하는 가정으로 진행했다.

## 이미지 제작 기획과 다음 순서

상세: [신규 CG 다양화와 RTX 5090 상시 제작 기획](../specs/2026-09-05-art-library-production-design.md).

1. 기존 원본은 보존한다. 설치된 SDXL·IP-Adapter·OpenPose로 정체성 참조와 얼굴 방향/몸 포즈/장면 구도를 분리한 24후보 파일럿을 먼저 제작한다.
2. 파일럿에서 동일 인물과 새 구도가 함께 유지되는지 확인한 뒤 SQLite 원장·재시작 복구·pause/resume·GPU 단일 워커·검수 화면을 구현한다. 현재 문서에 등장하는 새 워커/검수 스크립트는 구현 예정 경로다.
3. 6명×6장면×4후보(144후보)에서 36장면을 선별하고, 우선 12장면을 영상화한다. 제작량·채택률·GPU 시간을 측정하며 큐를 보충한다.
4. 성인 대상 보너스는 명백한 성인 인간 캐릭터의 비노골적 로맨스·특별 의상 화보를 6명×2장면으로 설계했다. 인연 에피소드 완료에 연결하며 별도 갤러리 표시·자산 접근을 후속 구현한다.
5. 사용자 배포 지시가 오면 이번 수정부터 push와 Fly 단일 머신 배포를 진행한다. 그전까지 공개 게임의 모습은 바뀌지 않는다.
