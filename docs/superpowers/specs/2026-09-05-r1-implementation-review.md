# R1 구현 독립 리뷰와 총괄 판정

기준: R1a `cd85f46`, R1b `25738a9`. Claude Code CLI 요청 `--model fable --effort xhigh`, 실제 결과 `modelUsage.claude-fable-5-1` 확인. 결과 원본은 로컬 git 제외 `qa-tmp/expansion-reviews/r1-implementation.ndjson`.

Fable은 P1 차단 문제 없이 머지 가능으로 판단했고 P2 2건·P3 1건을 제시했다. 총괄은 아래와 같이 판정했다.

| 항목 | 판정 |
|---|---|
| 시작 소급의 전체 스냅샷 검증이 streak 등 무관한 상태 손상까지 서버 기동 차단 | 수용. 프로필 존재 확인은 좁히고 지급 후보/증빙/트리거/오류 전파는 유지. 없는 프로필 생성은 여전히 금지 |
| 실패 씬 헤더 포기가 결산/재도전까지 폐기 | 수용. 실패 씬에서는 헤더 포기를 숨기고 [결산 보기]로 이동. 서버의 명시 abandon 폐기 계약은 유지 |
| 만료 실패 씬의 resend가 종료 뷰와 room-lost를 겹쳐 전송 | 작은 보정 범위에서 수용. 같은 호출이 종료 뷰를 보냈다면 resend 성공으로 취급하는 회귀 포함 |

실제 실행: 기존 관련 단위 85개 + 실제 소켓 11개 + 임시 독립 프로브 8개, 모두 통과. 프로브는 검토자가 생성·실행·삭제했다. 전체 suite/build/tsc/lint/브라우저는 이 리뷰에서 실행하지 않았으며 담당 검증과 총괄 통합 검증으로 구분한다.

반증 확인: story-linked 영수증이 있는 프로필/장착 아이템 cascade 삭제 정상, 영수증 INSERT OR REPLACE 차단, failScene 없는 실패→terminal→retry→성공 1회, 포기/만료 정리. 수기 코드 대조와 실제 실행된 범위를 리뷰 원문에 구분해 두었다.

총괄 추가 관찰: 실제 모바일 Chrome에서 실패 씬/실패 결산의 페이지 새로고침 복원과 재도전 새 스택·미션 시작 확인. 잔액 갱신·이미 획득한 보상 잠금 미리보기·첫 테이블 안내·보너스 목표 문구·실패 대사의 재현 문제는 `2026-09-05-r1-live-qa.md`에 기록하고 R1c로 함께 수정한다.
